# Dashboards

Personal at-a-glance pages, served with GitHub Pages:

- **Home** (`index.html`) – today's weather, Utah/BYU and NFL games, Delaware River level
- **Weather** (`weather.html`) – Easton, PA conditions, forecast, last 7 days, sun, air quality, river gauge
- **College** (`college.html`) – Top 25 scoreboard with Utah and BYU spotlight, poll, projected CFP field, Big 12 race
- **NFL** (`nfl.html`) – this week's games, Broncos playoff path, playoff picture, divisions

Everything runs in the browser from public data feeds (National Weather Service, NOAA, Open-Meteo, ESPN). No keys or personal data are stored here.
